# GoalZone

GoalZone is a premium, mobile-first football platform built around the FIFA World Cup 2026 hype cycle while showcasing major global football experiences.

## Stack

- Next.js 15 App Router
- TypeScript strict mode
- Framer Motion
- Zustand
- TanStack Query
- @ducanh2912/next-pwa with Workbox PWA support

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

Copy `.env.example` to `.env.local` and fill provider keys before connecting live Firebase, API-Football, YouTube, or OpenAI services.
